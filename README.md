# FastAPI Template

A production-ready FastAPI template following a layered architecture and modern Python development practices.

## Goals

This template is designed to provide:

- Clean project structure
- Separation of concerns
- Maintainable code
- Easy testing
- Scalable architecture

## Technology Stack

- Python
- FastAPI
- Pydantic v2
- SQLAlchemy 2.x
- SQLite (development)
- PostgreSQL (production-ready)
- Alembic
- Pytest

## Project Structure

```
project/
│
├── app/
├── docs/
├── tests/
├── AGENTS.md
└── README.md
```

## Documentation

Project documentation can be found in the `docs` directory.

- project-rules.md
- architecture.md

## Development Workflow

1. Read the project documentation.
2. Implement changes following the architecture.
3. Keep documentation updated.
4. Write tests when appropriate.
